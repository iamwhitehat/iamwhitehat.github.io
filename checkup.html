Cursor, Lovable and Claude build fast, and they leak the same way every time: API keys in client code, endpoints with no auth, SQL built from user input. Paste your public repo or live site below. You get back a plain verdict and one copy-paste fix prompt per finding, ready for Cursor or Claude.

Public repos / sites you have rights to scan only. Secrets in reports are always redacted. Limit 5 scans per day.

What you get back

  1. A plain verdict. "We found 2 live secrets and an open admin endpoint." No severity matrices.
  2. Fix prompts. One per finding, written to paste straight into your editor: what's wrong, exactly what to change, how to verify it worked.
  3. Redacted evidence. Receipts that the finding is real, with secrets masked.

Repo vs site?

The repo scan reads source code and finds deeper wounds (injection, missing auth, secrets in git history). The site scan probes what's exposed on the internet right now (open .env files, visible .git folders, expired certificates, broken links). If you can, run both.
