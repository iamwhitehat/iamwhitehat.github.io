Every Patchhound fix goes through the same five-level gate whether it's a €490 job or a free open source patch:

01

Reproduce

We never fix from assumption. The bug is reproduced first — if we can't reproduce it, we say so.

02

Discriminating tests

Tests must fail on the broken code before they're allowed to pass on the fixed code. Both numbers go in the report.

03

Live verification

The real server gets hit with the real request. Blocked before, working after — shown in the report.

04

Blast radius

Full test suite run. We check the fix didn't break the three things nobody thought about.

05

Hostile read

The diff gets reviewed as if by a skeptical stranger. If we wouldn't accept it, you don't see it.
